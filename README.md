## 💰 Finance — Controle Financeiro Pessoal

Aplicação Web desenvolvida para auxiliar no gerenciamento financeiro pessoal.

Principais objetivos:

* controle de receitas;
* controle de despesas;
* acompanhamento de pagamentos;
* organização financeira;
* carteira de investimentos;
* criação de reserva de emergência;
* visualização da evolução financeira.

### Tecnologias

`TypeScript` • `Node.js` • `Express` • `Supabase` • `PostgreSQL` • `Vercel` • `Render`
